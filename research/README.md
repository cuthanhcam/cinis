# Research spikes

Timebox each initial spike to 4-8 focused hours. Reports record question, assumptions, environment/toolchains, commands, observed results, limitations, decision, and follow-up.

## Rust matching

One book, safe Rust, ordinary collections, limit GTC, partial fill, cancel. Demonstrate sell 10 at 100, buy 4, cancel 6. Identify numeric/capacity constraints and learning gaps. This does not prove financial/durability guarantees.

## .NET/Rust protocol

One framed TCP loopback command/result. Test split/multiple frames, invalid lengths, disconnect before/after submission, timeout/retry IDs. Record serialization interoperability and explicit bounds. Shared memory is deferred.
