# Cinis

A deterministic trading venue simulator with a Rust execution core and a .NET management platform.

Cinis explores matching, pre-trade risk, durable execution, recovery, and reproducible performance measurement. The initial target is one spot market with synthetic funds.

## Status

Repository foundation only. Product specifications, architecture, development workflow, and repository checks are being integrated on develop for a subsequent pull request. No executable application exists yet.
