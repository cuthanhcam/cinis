# Commit messages

Use `type(scope): imperative description` in English. Types: feat, fix, docs, test, refactor, perf, build, ci, chore, revert. Scopes may include engine, platform, domain, protocol, recovery, repo.

Examples: `docs(domain): specify price-time priority`; `test(engine): cover partial fill and cancel`.

Describe delivered changes. Use the body for rationale, rule IDs, verification, and limitations. Mark breaking contracts with ! and a BREAKING CHANGE footer. Never include credentials or claim future functionality.
