# Security policy

There is no supported executable release yet. The initial target uses synthetic assets in a controlled development environment.

Do not publish credentials or exploitable details in public issues. Contact the maintainer through an established private channel; a dedicated reporting address is not configured. Use hosted private vulnerability reporting if the maintainer enables it later.

Provide affected revision, reproduction steps, impact, and mitigation. Response times are not guaranteed for this personal project. Rotate exposed credentials through their issuing service.

See [security model](docs/architecture/security.md).
